## 🎨 Features
| **Feature** | **Description** |
|-------------|----------------|
| 🌓 **Dark/Light Mode Toggle** | Easily switch between light and dark themes. |
| 🏄 **Smooth Scrolling** | Navigation links scroll smoothly to sections. |
| 🎉 **Scroll Animations** | Sections fade in as you scroll down the page. |
| 💻 **Interactive Project Cards** | Flip on hover to reveal live demo links. |
| 📱 **Responsive Design** | Looks great on desktop, tablet, and mobile devices. |
| 😄 **Fun About Me Section** | Skills highlighted with emojis and playful styling. |
